# Klang Games

> Klang Games is an entertainment and game development studio in Berlin, founded in 2013 by three Icelandic co-founders out of the EVE Online orbit. Its flagship product is SEED, a persistent large-scale MMO society simulator run on Google Cloud. Klang publishes no developer platform, no API documentation and no SDKs; the only publicly discoverable machine interface is the OpenID Connect provider behind SEED player accounts.

## Machine interfaces

- [OIDC discovery (seed.game)](https://seed.game/.well-known/openid-configuration): Issuer https://seed.game.
- [OIDC discovery (login.seed.game)](https://login.seed.game/.well-known/openid-configuration): Same endpoint set; advertises the unchanged FusionAuth default issuer `acme.com`.
- [JWKS](https://login.seed.game/.well-known/jwks.json)
- Authorization: https://login.seed.game/oauth2/authorize
- Token: https://login.seed.game/oauth2/token
- Device authorization: https://login.seed.game/oauth2/device_authorize
- UserInfo: https://login.seed.game/oauth2/userinfo
- Scopes: `openid`, `offline_access`, `email`, `phone`, `profile`

## Notes

- There is no OpenAPI, AsyncAPI, GraphQL schema, webhook catalog, CLI, sandbox, changelog or client SDK published by Klang. Those artifacts are absent from this repo by design, not by omission.
- No `/.well-known/security.txt` and no published vulnerability disclosure or trust-center program were found on any Klang or SEED host.
